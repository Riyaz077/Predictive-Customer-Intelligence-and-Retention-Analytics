# Dataset Dictionary

customer_id: synthetic unique identifier. recency_days: days since last purchase. frequency: number of purchases in the observation period. monetary_value: historical customer spend. tenure_months: customer tenure. avg_order_value: average transaction value. support_tickets: support interactions. engagement_score: normalized engagement indicator from 0 to 1. churned: synthetic binary churn label. future_value: synthetic target for future customer value.
